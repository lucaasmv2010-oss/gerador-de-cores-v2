# Gerador de Cores V2

Aplicação web desenvolvida com HTML, CSS e JavaScript para gerar paletas com cinco cores HEX aleatórias.

## Sobre o projeto

Este projeto faz parte da minha trilha de estudos em desenvolvimento web. A V2 evolui o gerador de uma única cor para uma paleta com cinco cores geradas dinamicamente.

## Funcionalidades

- Geração de cinco cores aleatórias
- Cores em formato HEX
- Nova paleta a cada clique
- Carregamento automático de uma paleta ao abrir a página
- Interface responsiva
- Efeito visual ao passar o mouse sobre os cards

## Tecnologias

- JavaScript
